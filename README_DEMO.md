# 📊 PinSight_AI

## AI品牌与市场增长工作台 · 产品介绍

---

> **让企业轻松获客的智能品牌管理与市场增长工具**

---

## 🎯 产品概述

随着生成式AI、AI搜索和内容自动化工具快速发展，企业品牌与市场部门的工作正在从一次性营销策划，转向长期化、流程化、智能化的能力建设。

**AI品牌与市场增长工作台** 正是为此而生 —— 一套可持续使用的AI工具能力，帮助企业长期开展品牌诊断、产品分析、市场定位、内容生成、推广策略制定和效果复盘。

---

## ✨ 核心功能模块

### 🔍 品牌分析（核心功能）

**输入：** 企业官网 / 官方介绍 / 官方社媒内容

**输出：**
- 品牌定位分析
- 品牌关键词提取
- 品牌调性评估
- 目标客户画像
- 品牌优势与风险提示

---

### 📦 产品分析（核心功能）

**输入：** 选定品牌的代表性产品或产品线

**输出：**
- 产品功能拆解
- 用户痛点匹配
- 核心卖点提炼
- 使用场景分析
- 竞品参考对比

---

### 🎯 市场定位分析（核心功能）

**输入：** 品牌信息、产品信息、目标消费者和渠道信息

**输出：**
- 目标客群分析
- 细分市场定位
- STP/SWOT 分析框架
- 差异化定位建议
- 渠道建议

---

### 🌐 GEO/AI搜索可见度分析（增强功能）

**什么是 GEO？**
> Generative Engine Optimization - 优化品牌在AI搜索（如ChatGPT、Claude）中的可见度

**分析维度：**
- AI回答中品牌出现频率
- 品牌描述准确性
- 竞品对比分析
- 内容补强建议

**合规要求：** 只优化真实信息，不使用刷屏、灌水、伪造等手段

---

### ✍️ 内容工坊（核心功能）

**支持的平台：**
| 平台 | 内容类型 |
|------|----------|
| 📱 小红书 | 种草文案、攻略笔记 |
| 🎬 抖音 | 短视频脚本、口播文案 |
| 📝 公众号 | 推文开头、专题文章 |
| 📣 广告 | 海报标题、宣传语 |
| 👥 KOL合作 | Brief、投放建议 |

**自动合规：** 生成内容自动通过合规审查

---

### 📰 舆情分析（增强功能）

**数据来源：** 公开评论、新闻摘要、社媒样本

**分析维度：**
- 正负面倾向识别
- 核心关注点归纳
- 风险等级评估
- 典型疑虑挖掘
- 回应建议生成

---

### 🛡️ 合规卫士（核心功能）

**检测类型：**
| 风险类型 | 示例 |
|----------|------|
| ❌ 绝对化用语 | "最好"、"第一"、"顶级" |
| ❌ 虚假宣传 | 无法证实的功效声明 |
| ❌ 贬低竞品 | 负面比较表述 |
| ❌ 版权侵权 | 未授权素材使用 |
| ❌ 隐私泄露 | 个人信息暴露 |

**输出：** 合规报告 + 修改建议

---

### 🔄 竞品分析（增强功能）

**对比维度：**
- 品牌定位对比
- 产品卖点差异
- 渠道表达策略
- 内容营销方式
- 市场表现评估

## 💼 案例演示：喜茶品牌分析

### 📍 品牌定位
高端新茶饮品牌，主打"灵感之茶"，定位年轻都市白领

### 🎨 品牌调性
简约时尚、高端精致、年轻活力、跨界创新

### 👥 目标客群
22-35岁都市白领、年轻中产、追求品质的Z世代

### 💪 竞争优势
产品创新力强、品牌设计独特、数字化运营成熟

---

### ✍️ 生成的营销文案

**小红书文案：**
> ✨ 喝一口就是春天的味道！喜茶新品「多肉青提」也太好喝了吧～
> 清新的青提果香搭配绵密芝士，一口沦陷！拍照也是绝绝子📸

**推广标语：**
> "灵感之茶，遇见美好" / "一口喜茶，满满灵感"

## 🔧 使用方法

### 方法一：本地运行
```bash
# 克隆项目
git clone https://github.com/jennyjunqiuhe921/brandpulse-ai.git

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入 API Key

# 运行
streamlit run main.py
```
