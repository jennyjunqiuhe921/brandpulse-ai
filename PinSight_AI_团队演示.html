使用指引
三步开始测试
1
打开应用，确认连接
点击页面顶部「打开应用」按钮，直接访问云端部署版本 pinsight-ai.streamlit.app，无需本地安装。
2
在侧边栏选择品牌
左侧侧边栏「分析品牌」区域选择想要测试的品牌（喜茶、奈雪、新东方、淘宝均可）。 切换品牌后，所有模块自动联动该品牌数据，无需重新配置。
3
逐模块点击运行
点击侧边栏「功能模块」中的任意模块，进入后点击「运行」或「开始采集」按钮即可查看 AI 分析结果。 演示模式下无需 API Key，约 1-2 秒返回预置演示数据。 若已配置 ANTHROPIC_API_KEY，将实时调用 Claude 动态生成。
4
测试品牌新增与知识库
进入「品牌管理」→「新增品牌」，填写任意品牌信息后保存。 切换到该品牌，在「知识 库」标签上传 PDF 或输入文本，再运行品牌分析—— AI 将基于你上传的内容生成专属洞察。
📋 测试注意事项
✓ 演示模式下所有数据均为示例预览，不消耗 API 额度
✓ 可同时多人访问同一应用地址，数据互不干扰（各自的浏览器 session 独立）
⚠ 删除演示品牌（喜茶/奈雪）后需重启应用才能恢复
⚠ 知识库上传的文件存储在本地，重启不丢失，但请勿上传敏感商业数据
