## 二、技术架构延续

- **单 Streamlit + st.navigation**：按角色动态菜单；**运营端用独立入口/独立会话**（满足 2.8 物理隔离）
- **数据库**：扩展 SQLAlchemy 模型，新增：消息、审批、Prompt、模型配置、公共资源、选品任务、竞品主体/情报、GEO复测对比记录、套餐
- **AI 网关**：升级 `core/llm_client` → 路由 + 计量 + 限流 + 调用日志（按租户/按 Prompt 分类）
- **工作流引擎**：通用状态机承载审批/复核
- **生产库**：Supabase / Neon Postgres（Secrets 配置；本地 SQLite 开发）

## 三、分阶段实施计划（对齐 V1.2）

### Phase S1 · 全局基础设施
1. 标准页面范式：顶部导航栏 + 底部状态栏（AI调用数/数据来源/合规/版本/操作人）
2. 全局消息中心（审批/任务/风险/竞品异动/GEO异常/报表/公告；已读筛选；弹窗+消息双提醒）
3. 任务通用规则：`优先级/标签/截止时间` 全任务统一 + 列表/看板双视图(拖拽) + 超时高亮
4. 数据对比与下钻：同比/环比/行业均值 + 指标下钻明细 + 多组历史横比趋势
5. AI 网关升级（计量/限流/调用日志）
6. 工作流引擎（统一状态机）
7. 文件服务 + 水印（企业名/操作人/时间）

### Phase S2 · 审批闭环 + 执行层增量 + GEO 复测评估
1. **多级审批中心**：待我审批/我已审批/我发起；单级+多级+多条件分支；驳回评论(段落高亮)、修改重提留痕、版本diff、催办、意见模板、在线协作评论区
2. **我的审批** + 管理层方案终审
3. **文案增量**：侧边素材栏、分支版本树+版本备注、多平台预览、热度评分(0-10)、模板三层分类
4. **⬆️ GEO 复测 + 前后对比 + 效果评估**（V1.2 重点）：
   - 输入加「关联历史任务 / 对比基准周期」
   - 自动算指标差值/提升%/效果评级（优秀≥20%/良好10-19%/一般0-9%/无效）
   - **GEO 历史对比&效果评估详情页**（指标对比表/趋势曲线/评估区/人工批注/导出）
   - 任务列表加「有无对比/效果评级」筛选 + 「基于本轮新建复测」
5. **舆情增量**：传播可视化、细分标签(人群/地域/场景/情绪)、负面案例库、工单分级处置(0-4级时效)
6. **工作台升级**：任务聚合、看板、超时提醒、按角色个性化首页
7. **个人中心**：资料/密码/消息/帮助

### Phase S3 · 🆕 新增执行模块：智能选品 + 竞品情报仓库
1. **商品智能选品**：选品任务列表/新建(行业/品类/维度标签/区域/选品目标/对标竞品)、全域数据总览、综合评分(热度30+口碑30+差异化20+合规20)、推荐清单、合规专项、配套物料(跳文案)、报告导出、行业选品模板、与竞品/舆情/文案联动
2. **竞品情报仓库**：竞品主体管理(批量增删/启停/归档)、监控配置(频率/渠道/六维度)、**六大情报标签页**(品牌/产品/舆情/GEO/文案/策略)、综合对标报表、历史情报归档(回溯对比)、预警规则(上新/调价/活动/负面/排名异动)、与选品/品牌分析/舆情/GEO 双向联动

### Phase S4 · 管理层（企业领导端）
1. **管理驾驶舱**：7 子看板(品牌总览/内容运营/舆情口碑/GEO搜索/渠道效果/**选品数据**/**竞品情报**) + ROI价值看板 + 自定义报表(定时推送) + 数据下钻 + 同比环比对标 + 地域热力图
2. **GEO 全局对比汇总报表**（管理层专属）：全公司复测对比、效果评级分布、按时间/部门/品牌拆分
3. **组织架构与账号权限**：部门/门店/子品牌架构、自定义角色、批量复制
4. **各模块管理视角**：企业级任务列表(只读全员)、内容抽检、方案终审
5. **合规审查 & 审计台账**：违规统计、防篡改审计日志(监管格式导出)、企业私有合规词库
6. **企业资产库**(密级:公开/内部/机密) + **企业系统设置**

### Phase S5 · 运营侧（平台管理员后台）
1. **🔒 运营端独立登录页**：专属入口、无注册、与品牌端会话物理隔离
2. **租户管理**：增删改/套餐额度/冻结注销(90天归档)/数据概览
3. **大模型统一配置中心**：文本/生图/生视频接入、连通测试、状态机、额度拦截
4. **Prompt 统一管理中心(6 分类)**：文案/GEO/舆情/通用/**选品**/**竞品**；版本/diff/回滚/启停/内置基线
5. **公共资源库**：文案模板、合规词库&规则、GEO提问库、舆情词库、**行业选品模板**、**竞品情报基础配置**
6. **系统全局配置**(RBAC矩阵/审批模板/存储导出水印) + **采集全局规则**(L1/L2/L3)

### Phase S6 · 商业化收尾
1. **版本权限矩阵**：三档套餐功能开关(含选品/竞品/GEO复测分档)，按租户 `plan` 控制
2. **行业模板市场 + 冷启动向导**：奶茶/美妆/餐饮包(含选品配置)、管理员首登 5 步向导
3. **移动端适配复查 + 安全加固**：核心查看/审批移动可用、加密、越权双重校验
4. **上线**：接 Supabase/Neon Postgres、Secrets、回归测试、试用验收

## 五、开工前确认（4 个决策）

1. **阶段顺序**：按 S1→S6 全量推进，还是先冲某一块（如 S4 管理驾驶舱 / S3 选品+竞品）？
2. **数据隔离粒度**：执行层「只看我的 vs 看全员」是否现在按角色细分？
3. **生产数据库**：何时接 Supabase/Neon（建议 S4 后、上线前）。
4. **数据采集 & 竞品/选品数据**：仍用模拟数据演示，还是接第三方合规数据源？（影响成本/合规）
