# 智营 AI · GEO 区域竞争指数监测方案（G5）

> 来源：外部 PRD《AI-GEO 区域竞争指数监测系统 V1.0》
> 定位：把 GEO 从"全国/平台层面"下沉到**省份维度**的区域竞争情报。
> 状态：方案存档（未写代码）。合规：纯监测+分析+建议，无刷量/自动发布，符合底线。

## 一、核心增量
省份 × 5/8 个 AI 平台 提及率 → **加权综合「区域竞争指数」** → 全国热力地图 → 竞品分省对比 → 预警 → **AI 分省优化建议**。

## 二、对照现有 GEO
- ✅ 已有：8 平台收录监测(G4)、多主体隔离、竞品参数、轮次趋势
- 🆕 缺：省份维度、加权综合指数、热力地图、竞品分省对比、同比环比(分省)、重点省份标记、GEO 预警、AI 分省建议结构、PPT/Excel 导出

## 三、G5 子模块规划
| 子项 | 内容 |
|---|---|
| G5-1 区域指数监测 | 省份×平台提及率 + 可调权重加权综合指数 |
| G5-2 全国热力地图 | 按竞争指数渲染中国省份地图（Demo 先用分省条形榜，地图后置加 plotly） |
| G5-3 竞品分省对比 + 同环比 | 己方 vs 竞品分省指数差 + 涨跌幅 |
| G5-4 重点省份 + 预警 | 标记关注省 + 环比大幅下滑/落后竞品超阈值 → 消息中心 |
| G5-5 AI 分省优化建议 | 用 PRD 原 prompt：风险预警省份排序 / 优先级布局(攻坚/维护/观察) / 分平台落地动作 |
| G5-6 报告导出 | 分省+竞品+趋势+建议（先 Markdown，PPT/Excel 后续） |

## 四、AI 建议系统 Prompt（PRD 现成，可直接接入）
角色：AI 搜索流量运营策略顾问（餐饮/茶饮）。输入：各省综合指数、近7天环比、竞品分省差值、各平台曝光、重点省份、行业。
输出三板块：① 风险预警省份排序 ② 优先级布局(攻坚/维护/观察) ③ 分平台落地执行动作(7天极简清单)。300-600字、序号分段、可直接落地。

## 五、与舆情的交汇 💎
舆情人工确认的**高频负面话题** → 推送 G5 → 输出"前置问答优化建议"。打通"口碑问题→GEO内容布局"闭环。
