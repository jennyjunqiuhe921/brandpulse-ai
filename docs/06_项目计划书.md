# 智营 AI · 一体化 AI 营销 SaaS 平台 — 项目计划书

> 版本：v1.0　|　编制日期：2026-06-11　|　产品形态：B 端标准化 SaaS（PC 为主，移动辅助）

---

## 一、项目背景

### 1.1 行业痛点

消费品牌（尤其是连锁餐饮、新茶饮、美妆等）在数字化营销中普遍面临四大难题：

1. **工具碎片化**：文案用一个工具、舆情用一个工具、竞品又一个工具，数据不互通，团队在多个系统间反复切换，效率低下。
2. **AI 内容不可控**：直接用通用大模型生成营销内容，存在事实错误、广告法违规、品牌调性走样、AI 幻觉等风险，缺乏合规与人工复核机制。
3. **管理层看不见价值**：一线在忙，但高管难以量化营销投入产出（ROI），缺乏统一的数据驾驶舱与决策依据。
4. **AI 搜索时代的新战场**：用户越来越多通过 AI 问答（而非传统搜索）了解品牌，"在 AI 回答里品牌是否被提及、描述是否准确"成为新的可见度战场，但市面上几乎没有成熟工具应对（GEO，生成式引擎优化）。

### 1.2 项目定位

**智营 AI** 是面向全行业品牌、连锁企业、集团公司的一体化 AI 营销 SaaS 平台，打通**数据采集 → AI 分析 → 品牌诊断 → 内容创作 → 风险校验 → 流程审批 → 资产复用 → 竞品监控 → 选品决策 → GEO 优化**的完整营销闭环。

一句话定位：**「AI 营销 + 合规风控 + 智能选品 + 竞品情报 + GEO 优化」五位一体的企业级营销工作台。**

### 1.3 差异化

以营销学、NLP、GEO、舆情传播、STP/SWOT 等方法论为底层支撑，将"工具 + 方法论 + 数据"三位一体，区别于市面上单一功能的文案工具或舆情工具。**强合规、强管控、强方法论**是核心壁垒。

## 二、产品与技术方案

### 2.1 三端架构

| 端 | 角色 | 核心能力 |
|---|---|---|
| **运营端**（平台方） | 平台管理员 | 多租户管理、大模型配置、Prompt 中心、公共资源库、采集全局规则 |
| **管理端**（品牌方高管） | 企业领导/法务/内审 | 7 看板管理驾驶舱、ROI 价值看板、多级审批、合规审计台账、组织架构 |
| **执行端**（品牌方一线） | 市场/文案/公关 | 数据采集、AI 文案、GEO 优化、舆情处置、智能选品、竞品情报、合规自查 |

### 2.2 核心功能模块（已落地）

1. **全平台文案生成**：品牌锚定 + 场景分层 + 合规三层创作法，多平台适配、热度评分、AI 四区块标注（公开事实/AI推断/人工判断/待验证）。
2. **GEO 生成式引擎优化**：监测品牌在 AI 问答中的曝光与准确性，**周期复测 + 前后对比 + 量化效果评级（优秀/良好/一般/无效）**，形成"监测—优化—复测—验效—迭代"闭环。
3. **AI 舆情分析**：五级风险预警、情感聚类、**分级工单处置（0-4 级 SLA）**、负面案例库沉淀。
4. **商品智能选品**：市场热度 + 口碑 + 差异化 + 合规四维综合评分，输出推荐清单与合规专项。
5. **竞品情报仓库**：7×24 常态化监控，品牌/产品/舆情/GEO/内容/策略六维情报，异动预警。
6. **多级审批 + 合规风控**：多条件分支审批、版本 Diff、驳回重提、审计留痕（只增不改、可按监管格式导出）。
7. **管理驾驶舱**：7 大看板 + ROI 价值看板 + 自定义报表 + 同比环比对标 + 数据下钻。

### 2.3 技术底座

- **AI 网关**：统一路由所有大模型调用，集中计量、限流、调用日志；支持文本/生图/生视频多模型接入与热切换。
- **轻量化 Prompt 管理**：六大业务分类，版本管理 + Diff + 一键回滚，平台侧统一维护、租户侧无感升级。
- **多租户隔离**：物理级数据隔离（tenant_id），企业内按角色/部门/门店/子品牌分权。
- **合规引擎**：广告法违禁词库、绝对化用语检测、信息溯源强制留痕、人工复核门控。
- **工作流引擎**：全局统一状态机，覆盖审批/复核/任务。

### 2.4 技术栈

- 前端/应用层：Streamlit（快速交付级 SaaS，支持后续 React 重构）
- 数据层：SQLAlchemy ORM + PostgreSQL（生产）/ SQLite（开发），支持 pgvector 向量检索
- AI 层：可插拔大模型（Claude / OpenAI 兼容 / 国产模型），RAG 知识库（Chroma）
- 安全：bcrypt 密码加密、API 密钥掩码存储、前后端双重越权校验、审计不可篡改、文件水印
- 部署：双应用独立部署（品牌端 + 运营端物理隔离），共享 Postgres；Streamlit Cloud / 自有服务器均可

> 当前已完成 S1-S6 全模块的交付级实现，可直接用于商业演示、试用与赛事交付。

## 三、商业模式

### 3.1 收入模式：订阅制 SaaS（三档套餐）

| 套餐 | 目标客户 | 核心权益 | 定价建议（/年） |
|---|---|---|---|
| **基础执行版** | 单店/小型品牌 | 基础采集/文案/简易GEO/基础舆情/基础选品 | 0.8–1.5 万 |
| **标准管控版** | 成长型连锁 | + 多级审批/完整审计/全渠道采集/生图视频/完整GEO复测/舆情工单/全维选品/竞品情报 | 3–6 万 |
| **企业集团版** | 集团/上市公司 | + 多组织管控/监管级台账/批量任务/危机舆情/高阶报表 | 10–30 万 |

### 3.2 增值收入

- **按量计费**：AI 调用额度、采集条数超出套餐部分按量加购。
- **行业模板市场**：奶茶/美妆/餐饮等行业包，深度定制配置。
- **专业服务**：私有化部署、定制开发、品牌策略咨询、代运营。
- **数据增值**：行业 GEO 可见度报告、竞品情报订阅（合规公开数据）。

### 3.3 成本结构

- 大模型 API 调用（主要可变成本，AI 网关已做计量与限流控制）
- 云服务器与数据库（Postgres）
- 研发与运营人力
- 销售与市场获客

### 3.4 商业飞轮

工具提效 → 沉淀品牌资产与数据 → 切换成本提高 → 续费率提升 → 行业模板与方法论复用 → 边际成本下降 → 规模扩张。

## 四、市场前景

### 4.1 市场规模

- 中国营销 SaaS 市场处于高速增长期，企业数字化营销渗透率持续提升。
- AIGC + 营销的结合是确定性趋势，生成式 AI 正重塑内容生产与品牌触达方式。
- **GEO（生成式引擎优化）是蓝海赛道**：随着用户行为从"搜索引擎"向"AI 问答"迁移，品牌在 AI 回答中的可见度管理将成为刚需，目前几乎无成熟竞品。

### 4.2 目标市场

- **首选行业**：新茶饮/连锁餐饮（标准化程度高、上新频繁、舆情敏感、合规要求严）。
- **扩展行业**：美妆护肤、快消、3C、本地生活服务。
- **客户画像**：拥有市场团队、有合规诉求、多门店/多品牌、重视品牌资产沉淀的连锁与集团企业。

### 4.3 竞争格局与壁垒

- 现有玩家多为**单点工具**（纯文案、纯舆情、纯 SEO），缺乏一体化闭环与合规管控。
- 智营 AI 的壁垒：**全链路闭环 + 强合规风控 + GEO 先发 + 方法论沉淀 + 多租户数据资产**。
- 越用越沉淀的品牌知识库与历史数据，构成长期的客户切换成本。

### 4.4 落地路径（Go-to-Market）

1. **赛事/标杆**：以行业赛事、标杆客户打样，验证产品价值。
2. **行业切入**：聚焦新茶饮单点突破，做深做透行业模板。
3. **渠道扩张**：通过 SaaS 渠道商、行业协会、代运营机构分销。
4. **生态延伸**：开放 API 与模板市场，构建合作伙伴生态。
