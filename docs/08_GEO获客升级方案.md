## 一、定位差异：我们「守」，文档「攻」

| | 现有 GEO 模块 | 外部文档的 GEO |
|---|---|---|
| 本质 | **监测诊断侧**：品牌在 AI 回答中是否被搜到、准不准、补强建议、复测评估 | **主动生产分发侧**：挖词→分平台批量生成→矩阵账号自动发布→线索回收 |
| 比喻 | 体检报告（守） | 获客流水线（攻） |
| 闭环 | 监测→优化→复测→验效 | 选词→生产→分发→收录验证 |

**结论**：两者互补。我们强在"诊断 + 合规 + 复测验效"，缺"从诊断往下走到生产→分发→收录验证"的获客闭环。本方案在**守住合规底线**的前提下补全这个闭环。

---

## 二、合规红线（必须先明确）

外部文档/系统中**以下部分坚决不吸收**，因其直接违反本系统合规底线（PRD §1.5.5 禁止刷量灌水操纵 AI 搜索；GEO Prompt 明令禁止刷屏诱导）：

| 不吸收项 | 原因 |
|---|---|
| RPA/Playwright 矩阵账号**自动批量发布** | 违反平台 ToS、账号会被封、属刷量操纵 |
| 防封控 / Stealth 隐身 / 防 MD5 判重 | 规避平台检测，高法律合规风险 |
| "成千上万篇文章灌水投放" | 本系统明确禁止的灌水操纵 |

> 注：连参考截图里那套商业 GEO 系统顶部都挂了合规声明（"优化仅限正规行业…勿违反广告法，否则后果自负"）。这反向印证：**合规是刚需**。而我们把合规做进**全链路审批+复核+审计**，是真正的差异化护城河——不能丢。

**自动分发那一层，我们用「导出发布包 + 人工合规发布」替代。**

## 四、最该抄的核心：多 AI 平台「收录监测」💎

截图最有价值的部分——按 AI 平台统计收录：
**deepseek / 豆包 / 腾讯元宝 / 通义千问 / 文心一言 / 纳米 / KIMI / 智谱**，每个显示"X 收录"。

这是 GEO 的**核心 KPI 看板**，也是我们现在最缺的。要补：
- **多 AI 平台收录率监测**：8 大国产 AI 平台，逐一统计"提及品牌 / 收录内容"比例
- **收录比例饼图 + 收录趋势曲线**（截图右下两图）
- **关键词占位率**：目标词在 AI 回答 / 搜索前 10 中自有内容占比
- 纳入现有「GEO 复测对比评估」，形成完整闭环

KPI 借鉴外部 PRD：收录率、关键词占位率、CPL（线索成本，可选回填）。

## 五、升级蓝图：GEO 获客工作台（合规版 8 步）

```
1 关键词蒸馏 → 2 素材准备 → 3 指令配置 → 4 AI批量创作 → 5 合规复核
→ 6 导出发布包(替代自动投喂) → 7 多平台收录监测 → 8 效果报表
```

| 阶段 | 做什么 | 复用 / 新建 |
|---|---|---|
| **G1 关键词蒸馏** | 长尾挖词（地域+产品+服务）、成交意图打分（高/低意图）、意图分类→平台分配（价格敏感→抖音 / B2B→知乎 / 决策参考→小红书） | 新建：GEO 表单升级 |
| **G2 内容批量创作** | 按平台模板批量生成草稿 + SEO 埋词（标题加"城市+产品"前缀、结尾插 CTA/联系方式）。平台模板：抖音(3秒痛点+7秒方案+5秒CTA)/小红书(数字情绪标题+Emoji+话题标签)/知乎(专家长文+避坑)/微博(150字快讯) | 复用内容工坊 + 新建批量入口 |
| **G2.5 合规复核** | 每篇过合规预检 + 人工复核 + 审批后方可使用 | 复用（差异化护城河） |
| **G3 导出发布包** | 生成"待发布清单"（词 / 平台 / 草稿 / 计划时间），导出，人工合规发布（替代自动投喂） | 新建 |
| **G4 收录监测看板** | 8 大 AI 平台收录率 + 饼图 + 趋势 + 关键词占位率，纳入复测评估 | 新建 ⭐ |

## 六、落地优先级

| 顺序 | 阶段 | 理由 |
|---|---|---|
| 1 | **G4 多平台收录监测看板** | 最像截图、最体现 GEO 价值、演示最抓眼球 |
| 2 | **G1 关键词蒸馏 + 意图分类** | 解决"做什么词"，获客起点 |
| 3 | **G2 批量创作 + SEO 埋词** | 打通"诊断→生产"，体感最强 |
| 4 | **G3 导出发布包** | 合规版分发闭环 |

> 演示阶段数据用模拟（如截图"0 收录"起步，跑几轮后有数）；接真实大模型 Key + 真实平台数据后升级为实测。

## 八、核心观点

把 GEO 从「体检报告」升级为「**选词→生产→验效**的获客引擎」，但**自动批量分发坚决不碰**——那是会被封号、被监管的黑灰产打法，与本系统"合规 SaaS"定位和护城河直接冲突。我们要做的，是**用合规方式补全获客闭环**，并以「多平台收录监测」作为最具说服力的价值证明。
