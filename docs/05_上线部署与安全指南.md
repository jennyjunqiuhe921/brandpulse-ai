# 智营 AI · 上线部署与安全加固指南（S6）

> 对齐 PRD V1.2 · 两套独立部署（品牌端 + 运营端）共享一个数据库

---

## 一、部署架构

| | 品牌方前台 | 运营方后台 |
|---|---|---|
| 入口 | `app.py` | `admin_app.py` |
| 角色 | 企业领导 / 市场人员 | 平台管理员 |
| 登录会话 | `auth` | `platform_auth`（物理隔离） |
| 数据库 | **同一个 Postgres** | 同一个 Postgres |

**关键**：云端两个 app 必须共享同一数据库 → 必须用 **Postgres**（不能用 SQLite，云端文件系统临时且不互通）。

## 二、本地运行（开发，SQLite）

```bash
# 终端 1 · 品牌端
streamlit run app.py                 # → localhost:8501

# 终端 2 · 运营端
streamlit run admin_app.py --server.port 8502   # → localhost:8502
```

- 市场人员：`staff1 / staff123`

## 三、生产上线（Postgres）

### 1. 建数据库（二选一，免费额度足够）
- **Supabase**：新建 project → Settings → Database → Connection string（URI）
- **Neon**：新建 project → 复制 connection string（含 `?sslmode=require`）

连接串形如：
```
postgresql://user:password@host:5432/dbname?sslmode=require
```

### 2. 配置密钥（不写进代码）
本地 `.streamlit/secrets.toml` 或环境变量：
```toml
DATABASE_URL = "postgresql://user:password@host:5432/dbname?sslmode=require"
```
> 代码已支持：`db/engine.py` 优先读环境变量 → st.secrets → 兜底 SQLite。无需改代码。

### 3. Streamlit Cloud（两个 App，共用同库）
- App 1：main file = `app.py`，Secrets 填 `DATABASE_URL`，Python 3.12
- App 2：main file = `admin_app.py`，Secrets 填**同一个** `DATABASE_URL`
- 依赖已在 `requirements.txt`：`SQLAlchemy / psycopg2-binary / bcrypt`

### 4. 首次启动
`init_db()` 自动建表 + 迁移 + 种子（默认账号/演示数据）。上线后**立即修改默认密码**。

## 四、安全加固检查表（S6-3）

| 项 | 状态 | 说明 |
|---|---|---|
| 密码加密 | ✅ | bcrypt 哈希，不存明文 |
| API 密钥 | ✅ | 大模型密钥仅存掩码；DATABASE_URL 走 Secrets |
| 多租户隔离 | ✅ | 所有业务表 tenant_id 过滤；跨租户返回空 |
| 登录物理隔离 | ✅ | 品牌端/运营端独立入口、独立会话键、独立部署 |
| 越权防护 | ✅ | 页面级 `is_admin()` / `require_feature()` 双重校验 |
| 审计不可篡改 | ✅ | AuditLog 只增不改，永久留存 |
| 文件水印 | ✅ | 导出含企业名/操作人/时间 |
| 默认密码 | ⚠️ 上线后改 | admin123 / staff123 / platform123 必须更换 |
| 文件服务器 | ⚠️ 禁用 | 切勿在项目根跑 `python -m http.server`（暴露 .env/.git） |
| HTTPS | ✅ Cloud 自带 | Streamlit Cloud 默认 HTTPS |

## 六、套餐分档（S6-1）

三档套餐按 `Tenant.plan` 控制功能可见性（`config/plan_features.py`）：
- **基础执行版**：基础采集/文案/简易GEO/基础舆情/基础选品
- **标准管控版**：+ 多级审批/完整审计/全渠道采集/生图视频/完整GEO复测/舆情工单/全维选品/竞品情报
- **企业集团版**：+ 多组织管控/监管台账/批量任务/危机舆情/高阶报表

运营端「租户管理」可调整任意租户套餐，品牌端菜单与功能随之解锁/隐藏。
