# 智营 AI · 舆情管控闭环升级方案（D5）

> 来源：外部 PRD《餐饮茶饮行业-AI 舆情管控系统 V1.0》
> 定位：把舆情从"分析工具"升级为"**接入→清洗聚类→定级→复核→工单→处置→消影→复盘→月度口碑**"全闭环。
> 状态：方案存档。合规：人工复核拦截、话术仅人工参考、不自动发布、不抓私域，符合底线。

## 一、对照现有「舆情中心」
- ✅ 已有：五级风险/情感分析/回应话术/工单(0-4级+SLA)/案例库/历史
- 🆕 缺：一二级情感标签+待验证、语义聚类去重、传播风险通俗预判、双口径话术+4场景、消影模块、结构化复盘+AI根因、月度口碑健康分、完整状态流转

## 二、D5 升级规划（按价值/差距排序）
| 子项 | 内容 | 优先级 |
|---|---|---|
| **D5-1 月度口碑健康分** | 五维模型(情感结构/负面占比/红标数/传播热度/风险权重)→0-100+一句评语，剔除待验证、已消影复盘降权 | ⭐ 先做 |
| **D5-2 双口径公关话术** | 对外公域口径 + 内部处置口径，4 场景模板(食安/团购退款/出餐慢/服务纠纷) | ⭐ 先做 |
| **D5-3 结构化复盘归档** | 橙红强制复盘(根因/影响范围/整改) + AI 根因建议一键填充 | 次 |
| **D5-4 消影模块** | 处置方式(公域回复/补偿/撤诉/置顶/电话和解)+标记已消除→停止告警 | 次 |
| D5-5 一二级情感标签 | 一级(正/中/负)+二级(维权/吐槽/建议/辱骂/服务纠纷)+待验证不计分 | 后 |
| D5-6 完整状态流转 | 待处理→处置中→待消影→待复盘→已归档 | 后 |
| D5-7 语义聚类去重 | 同事件合并(万条≤15s) | 后(需算法) |

## 三、6 个固定 Prompt（PRD 现成，可直接接入）
1. 情感多标签识别（一级+二级+待验证；食安强制负面-服务纠纷）
2. 语义聚类去重（事件合并，禁字面匹配）
3. 传播风险通俗预判（只输出 4 句，禁专业术语）
4. 双口径公关话术（对外公域 + 内部处置）
5. 五维口碑健康分（0-100 + 一句评语）
6. 复盘根因智能分析（根因分类 + 整改建议，一键回填）

## 四、合规红线（PRD 自带，与我们一致）
- 4 级红/食安强制人工复核拦截误判
- 话术仅人工参考，**系统不自动在第三方发布**
- 不抓私域，仅公域+手动导入
- 操作/消影/复盘日志不可删，永久留痕

## 五、与 GEO 的交汇 💎
人工确认的高频负面话题 → 推送 GEO(G5) → 前置问答优化建议。

## 六、落地优先级
**先做 D5-1 月度口碑健康分 + D5-2 双口径话术**（差距大、最出彩、prompt 现成、Demo 即可完整体验）→ 再 D5-3 复盘 / D5-4 消影 → 其余后续。
真实语义聚类/多平台抓取属后续，Demo 先模拟。
